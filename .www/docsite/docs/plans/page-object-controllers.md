# Plan: Page Object Controllers for Browser Testing

## Context

The browser-testing plan introduces Playwright-based integration tests for the docsite. This plan designs a companion abstraction: typed **Page Object Controllers** that wrap `playwright.Locator` and mirror ViewModel structure. The goal is to give tests a stable, typed API to interact with the DOM, with a generator that produces controllers automatically from `TemplateAnalyzer` output and `data-test-id` attributes.

---

## Decisions

| Question | Decision |
|---|---|
| Test-only or production? | Test-only |
| Wraps `playwright.Page` or `Locator`? | `playwright.Locator` (scoped) |
| Leaf element return type? | Typed wrappers (`*ButtonElement`, etc.) |
| Child controller exposure? | Methods (not fields) |
| Locator scoping? | Scoped within parent locator |
| `data-test-id` strategy? | Manual, kebab-to-PascalCase → method name |
| Root constructors? | Both `NewXxxController(page)` and `NewXxxControllerFromLocator(locator)` for every type |
| Generator invocation? | Deferred: `gen.Generate[T]()` + `gen.Run()` |
| Generator program location? | `.www/docsite/cmd/generate-controllers/main.go` |
| Generator discovery? | `//go:generate` comment in `harness.go` |
| Build tag? | `//go:build browser` on all generated files and element types |

## New Packages

### `torque/pkg/pageobjects` (hand-written, framework-level)

Contains two things: element wrapper types and the `Generator` API.

**Element wrappers** (`elements.go`, `//go:build browser`):
```go
type Element struct{ locator playwright.Locator }
func (e *Element) Locator() playwright.Locator { return e.locator }
func (e *Element) TextContent() (string, error) { return e.locator.TextContent() }

type ButtonElement struct{ Element }
func (e *ButtonElement) Click() error { return e.locator.Click() }
func (e *ButtonElement) IsDisabled() (bool, error) { return e.locator.IsDisabled() }

type InputElement struct{ Element }
func (e *InputElement) Fill(value string) error { return e.locator.Fill(value) }
func (e *InputElement) Value() (string, error) { return e.locator.InputValue() }

type AnchorElement struct{ Element }
func (e *AnchorElement) Href() (string, error) { ... }
```

**Generator** (`generator.go`, no build tag — it emits code, doesn't import playwright):
```go
type Config struct {
    OutputDir string // e.g. ".www/docsite/testutils/pageobjects"
    Package   string // e.g. "pageobjects"
}

type Generator struct { cfg Config; registrations []registration }

func NewGenerator(cfg Config) *Generator

// Generate[T] queues T for controller generation.
// T must implement torque.TemplateProvider.
func (g *Generator) Generate[T torque.TemplateProvider]()

// Run analyzes all registered types via torque.AnalyzeTemplate,
// then writes one *_controller.gen.go file per type to cfg.OutputDir.
func (g *Generator) Run() error
```

**Generator internals:**
- For each registered type, call `torque.AnalyzeTemplate(zeroValue)` to get `*TemplateAnalysis`
- Walk `analysis.HTMLTree` for `data-test-id` attributes → leaf element methods
  - `data-test-id="submit-button"` on `<button>` → `SubmitButton() *pageobjects.ButtonElement`
  - `data-test-id="email-input"` on `<input>` → `EmailInput() *pageobjects.InputElement`
  - Unknown/generic tags → `*pageobjects.Element`
- Walk `analysis.TypeTree.Children` for fields with `template:` struct tag → child controller methods
  - Child controller must also be registered; if not, generator emits a warning and skips
  - Scoping selector: child must have a `data-test-id` on its template root element; if absent, generator warns and uses the template name as fallback (`[data-test-id='{templateName}']`)
- Emit one file per type: `{typename_snakecase}_controller.gen.go`

## Generated Controller Shape

`.www/docsite/testutils/pageobjects/document_controller.gen.go`:

```go
//go:build browser

// Code generated by generate-controllers. DO NOT EDIT.

package pageobjects

import (
    "github.com/mxschmitt/playwright-go"
    "github.com/tylermmorton/torque/pkg/pageobjects"
)

type DocumentController struct {
    locator playwright.Locator
}

func NewDocumentController(page playwright.Page) *DocumentController {
    return &DocumentController{locator: page.Locator("html")}
}

func NewDocumentControllerFromLocator(locator playwright.Locator) *DocumentController {
    return &DocumentController{locator: locator}
}

// DocTitle is generated from data-test-id="doc-title" on <h1>
func (c *DocumentController) DocTitle() *pageobjects.Element {
    return &pageobjects.Element{Locator: c.locator.Locator("[data-test-id='doc-title']")}
}

// NavBar is generated from NavBar field with template:"navbar"
func (c *DocumentController) NavBar() *NavBarController {
    return NewNavBarControllerFromLocator(c.locator.Locator("[data-test-id='navbar']"))
}
```

## Generator Program

`.www/docsite/cmd/generate-controllers/main.go`:
```go
package main

import (
    "log"
    "github.com/tylermmorton/torque/pkg/pageobjects"
    "github.com/tylermmorton/torque/.www/docsite/routes"
    "github.com/tylermmorton/torque/.www/docsite/viewmodel"
)

func main() {
    gen := pageobjects.NewGenerator(pageobjects.Config{
        OutputDir: ".www/docsite/testutils/pageobjects",
        Package:   "pageobjects",
    })
    gen.Generate[*routes.Document]()
    gen.Generate[*viewmodel.NavBar]()
    if err := gen.Run(); err != nil {
        log.Fatal(err)
    }
}
```

Add to `harness.go`:
```go
//go:generate go run ../../../../cmd/generate-controllers
```
